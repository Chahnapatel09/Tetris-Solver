🧩 Tetris Solver

Welcome to my Tetris Solver! 🎮✨  

This project is a Java-based puzzle solver that intelligently places Tetris pieces on a grid to maximize your score while minimizing penalties. Think of it as a tiny AI brain 🧠 for Tetris — it plans ahead, thinks strategically, and clears rows like a champ! 🏆

🌟 Features

- 🎯 Strategic Solver: Uses smart placement and lookahead to optimize moves.  
- ⚡ Efficient & Fast: Precomputed rotations, fast board checks, and clever data structures make it lightning quick.  
- 🧠 Heuristic Guidance: Prioritizes row clearing and low-gap placements for maximum points.  
- 🏗️ Flexible Test Cases: Handles different board setups, multiple pieces, and variable lookahead depths.  
- 📊 Scoring System: Accurate points for cleared rows and penalties for leftover pieces.
